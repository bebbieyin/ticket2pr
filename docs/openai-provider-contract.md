# OpenAI Provider Contract

This document defines the boundary between the Ticket2PR workflow and the OpenAI coding-agent provider. It is a contract only; implementation belongs in Phase 3.

## Responsibility

The OpenAI provider turns validated ClickUp task context into repository changes and a structured implementation report.

The provider may:

- inspect the repository
- edit files
- add or update tests when needed
- run relevant tests and checks
- summarize implementation results

The provider must not:

- create commits
- push branches
- open, merge, or close pull requests
- update ClickUp status or comments
- choose the final commit message

The automation pipeline owns those GitHub and ClickUp lifecycle steps.

## Input

```ts
type OpenAIProviderInput = {
  clickupTaskId: string;
  clickupTaskUrl: string;
  taskType: "Bug" | "Feature" | "Enhancement" | "Chore";
  githubRepository: string;
  targetBranch: string;
  prBaseBranch: string;
  githubReviewerUsername: string;
  problemStatement: string;
  expectedBehavior: string;
  currentBehavior: string;
  contextOrReproductionSteps: string;
  relevantLinksLogsOrScreenshots: string;
  acceptanceCriteria: string;
  testExpectations: string;
  repositoryInstructions: string;
};
```

## Output

```ts
type OpenAIProviderOutput = {
  implementationSummary: string[];
  filesChanged: Array<{
    path: string;
    reason: string;
  }>;
  testsAddedOrUpdated: string[];
  testsRun: Array<{
    command: string;
    result: "passed" | "failed" | "skipped";
    notes?: string;
  }>;
  knownLimitationsOrFollowUpNotes: string[];
  prBodyData: {
    problemSummary: string;
    rootCauseOrRationale: string;
    implementationSummary: string;
    filesChanged: string;
    testsAddedOrUpdated: string;
    testsRun: string;
    knownLimitationsOrFollowUpNotes: string;
  };
};
```

## Commit Ownership

The OpenAI provider does not create commits. After the provider returns successfully, the pipeline should:

1. verify there are repository changes
2. generate the final commit message
3. validate the message with `pnpm commitlint:ticket2pr`
4. create the commit
5. open the pull request
6. update ClickUp

The final commit message must be generated by the pipeline using the Ticket2PR format from the ClickUp guide.
